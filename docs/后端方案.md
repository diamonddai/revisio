## 1. 创新点与困难

不通过“计算数值”来决定传播路径，而是通过模拟“人类认知决策模型”来自然涌现（Emerge）出拓扑结构。

**解决的核心困难：** 如何复现真实世界中异构且复杂的传播结构。

### 1.1 现有困境 (The Dilemma)

传统的传播模拟往往依赖「随机概率模型（Stochastic Probability Models）」——例如，系统设定「每个节点有 30% 的概率产生分支，70% 的概率线性转发」。

> [1] 提出 **Rational Agent** 框架，用以模拟和基准化人类对可视化的解读行为，并指出：传统的评估和模拟往往依赖简单的行为指标或随机假设，而忽略了人类在处理视觉信息时的「认知效用最大化」过程。

> However, several recent surveys of evaluative studies for visualizations [2] and uncertainty visualizations specifically [3,4,5] suggest that the use of well-defined judgment and decision tasks is rare. Instead, a majority of uncertainty visualization studies rely on measures of perceptual accuracy and/or self-reports of satisfaction, confidence, or other properties that may have an unclear or even opposite relationship with rational use of the information for the problem at hand [3,4,5].

近期多项针对可视化评估研究的综述 [2]，以及专门针对不确定性可视化的综述 [3,4,5] 表明，学界极少使用定义明确的判断与决策任务开展研究。相反，大多数不确定性可视化研究仅依赖感知准确性指标，或被试对满意度、自信心等维度的自我报告——而这些指标与针对具体问题理性利用信息的行为之间，可能存在模糊甚至相悖的关联。

> The value of the information presented in a visualization can be quantified by how much it improves the expected payoff in a decision problem. The visualized information reduces uncertainty about a payoff-relevant state, thus helping the agent make better decisions.

可视化所呈现信息的价值，可通过其在决策问题中提升预期收益的程度来量化；可视化信息能够降低与收益相关的状态不确定性，从而帮助主体做出更优决策。

**印证：** 传统评估方法未从「信息价值–收益最大化」的核心逻辑出发，忽略了人类处理视觉信息的理性决策本质。可视化领域的趋势是从「行为统计」转向「认知模拟」；传统的随机概率模型（Stochastic Models）属于旧范式，无法捕捉 Agent 在面对图表时的理性/非理性决策过程。

### 1.2 为何这是个困难 (Why it fails)

- **缺乏因果解释性：** 这类方法只能模拟「发生了分叉」，却无法解释「为什么在这里分叉」，切断了拓扑结构与传播内容之间的逻辑联系。
- **无法模拟社会学现象：** 真实世界中的「回声室效应（Echo Chamber）」是线性强化的结果，「极化对抗（Polarization）」是分支突变的结果；硬编码概率无法自然涌现（Emerge）出这些基于观点的复杂拓扑结构（如线性、树状、网状的混合体）。

### 1.3 创新点：叙事落差（Narrative Gap）→ 拓扑演化

> [6] 解释了为什么有些信息能够成功动员受众，而有些则被忽视或拒绝。

> What makes a framed message resonate with its audience? Resonance occurs when the framing aligns with the life experiences, beliefs, and cultural narratives of the targets. When frames lack resonance, they fail to mobilize and are often ignored or actively contested.

是什么让一个被框架化的信息与其受众产生共鸣？当框架与目标群体的生活经验、信仰和文化叙事相契合时，就会产生共鸣；当框架缺乏共鸣时，它们就无法动员受众，并经常被忽视或遭到积极对抗。

**与我们的关系：** 提供核心的社会学理论支撑。「共鸣导致线性传播」正是基于此理论，而叙事落差在数学概念上即为「框架共鸣度」的倒数。

> [7] 提出「同化–对比理论（Assimilation-Contrast Theory）」，揭示了受众在接收新信息时，基于自身既有立场的「认知距离」评估机制。

> Individuals evaluate incoming messages by comparing them with their existing anchor points. If the message falls within the latitude of acceptance, assimilation occurs (the message is perceived as closer to their own view). If it falls in the latitude of rejection, a contrast effect occurs (the message is perceived as more opposed to their view than it actually is).

个体通过将接收到的信息与其现有的锚定点进行比较来评估信息。若信息落在接受范围内则发生同化（信息被认为更接近自身观点）；若落在拒绝范围内则发生对比效应（信息被认为比实际更对立）。

**与我们的关系：** 对应系统设定的三种拓扑转向。落差小 → 同化（Minor 修改，线性累积）；落差大 → 对比（Major 修改，对抗与分支）；落差极大 → 拒绝/忽略（阻断传播）。说明基于「语义距离/落差」驱动网络拓扑生长的底层逻辑是可靠的。

| 落差 | 效应 | 行为 |
|------|------|------|
| 小 | 同化 | Minor 修改（线性累积） |
| 大 | 对比 | Major 修改（对抗与分支） |
| 极大/无关 | 忽略 | 停止传播 (Noise) |

> [8] 通过实证研究发现，真实世界中的图表误导和传播往往不是通过「视觉技巧（Visual Tricks，如截断坐标轴）」实现的，而是通过「叙事框架（Narrative Framing）」和「上下文操控」实现的。

概率模型通常基于「节点属性」或「图表类型」来设定传播概率；该文证明「内容叙事（Narrative）」才是误导和极化产生的核心。若不引入「叙事落差（Narrative Gap）」，模型就无法复现真实世界中基于观点冲突（而非视觉形式）产生的回声室或对抗分叉。

> [9] 用 LLM Agent 替代传统 SIR/概率模型进行传播模拟。文章表明，基于 LLM 的 Agent 能够通过理解内容语义（Semantic Content）而非硬编码规则，自然涌现出更接近真实社交网络的传播级联（Cascades）和同温层效应。

可作为技术路线（Technical Soundness）的直接依据，证明引入 LLM 计算「叙事落差」在工程上可行且优于传统方法。

### 1.4 Agent 建模与拓扑生成逻辑

将每个 Agent 建模为一个 **Gatekeeper**（会后特征、角色相关作为一个角色）。Agent 收到上一节点图表时，决策过程包含两个核心变量的比对：

- **输入帧（Incoming Frame）：** 上一节点传递过来的图表所表达的叙事（例如：「A 数据很危险」）。
- **自身偏见（Agent Bias）：** 该 Agent 被赋予的角色设定（基于 Taxonomy，如「网络影响者 + 对抗动机」）。

**拓扑生成逻辑（由 LLM 语义判断，而非数学公式）：** 系统通过 LLM 计算两者之间的叙事落差，从而自然涌现三种拓扑形态：

1. **共鸣（Resonance）→ 线性传播（Linear）：** 输入帧与 Agent 偏见一致时，Agent 仅做 Minor 修改（润色、加注释），形成单链。
2. **冲突（Conflict）→ 分支/突变（Branching/Mutation）：** 输入帧与 Agent 偏见严重冲突（叙事落差大）时，Agent 被激活「对抗（Adverse）」动机，进行 Major 修改（截断数据、换色），产生新分支节点。
3. **噪音（Noise）→ 阻断（Stop）：** 落差过大且无关时，Agent 选择忽略，链路在此终止。

## 2. 系统架构设计（基于 LangGraph）

使用 LangGraph 构建有状态的、循环的多智能体工作流。

### 2.1 全局状态 (Global State)

在 LangGraph 中定义 `GraphState`，包含：

- `visualization_artifact`: 当前图表的代码（Vega-Lite/Matplotlib）或图片描述。
- `narrative_context`: 当前图表所携带的文本叙事（标题、注释）。
- `provenance_chain`: 历史修改记录（用于 UI 的回溯分析）。
- `topology_map`: 当前节点连接关系（用于 UI 的力导向图渲染）。
- `global_intent`: 用户在 UI 设置的初始意图（恐慌/中立）。

### 2.2 智能体节点 (Agent Nodes)

三个核心 Agent 协同工作，形成循环：

**Node A：感知与评估**

- **职责：** 模拟人类看到图表的第一反应。
- **输入：** 上一节点的 Output（图 + 文）。
- **操作：**
  - 从 Taxonomy 的「角色库」中随机或指定抽取一个角色（如 Citizen Curator）。
  - **关键逻辑：** LLM 扮演该角色，阅读输入内容，输出「心理旁白（Inner Monologue）」。
  - 示例：*「我是个激进的博主，我看到这个图表虽然想表达中立，但数据里明显掩盖了某种趋势。我很生气（产生叙事落差），我要揭露它。」*

**Node B：策略制定**

- **职责：** 依据 Taxonomy 的规则，决定「怎么改」。
- **输入：** Node A 的心理旁白 + Taxonomy 规则库。
- **运用编码方案的启发：**
  - 应用编码方案。
  - Prompt 策略：*「你是一个 Network Influencer。根据研究，你倾向于使用 Data Selection 和 Text Reconstruction。你的动机是 Adverse。请选择具体的修改操作。」*
  - **决策输出：** Linear_Forward（微调转发）或 Branch_Out（引用并批判）。

**Node C：执行**

- **职责：** 实际修改代码或文本。
- **工具：** Python REPL（pandas, matplotlib）或图像处理工具。
- **输出：** 生成新的 Visualization Artifact，写入 `topology_map`，更新 Log。

### 2.3 边与路由 (Edges & Routing)

- **动态路由 (Conditional Edge)：**
  - 若 Node B 决定 `Branch_Out`，系统在 Graph 中分叉，并生成新的 Agent 实例处理该分叉。
  - 若 Node B 决定 `Stop`，该路径结束。

- **Data Ops** → `data_range_selector` tool
- **Text Ops** → `annotation_injector` tool

| 统计规律（如 64% Pro→Pro） | Temperature/Bias Settings |
|---------------------------|---------------------------|

## 4. 适配 UI 的交互流程

### 4.1 后端如何响应前端

**1. 初始化 (Setup)**

- 用户上传图片/数据 → 后端初始化 Gen0_Agent。
- 用户设置 Global Intent（如「恐慌化」）→ 后端将其作为 Environment Variable 注入所有 Agent，轻微偏移所有 Agent 的「自身偏见」。

**2. 运行模拟 (Simulation Run)**

- **UI 实时日志 (Live Log)：** 直接流式输出 Node A 的「心理旁白」和 Node B 的「策略选择」。
  - 示例：*Log: "Agent #3 (Influencer) felt the chart was boring. Strategy: Add annotation to highlight outliers."*
- **拓扑图更新：** 每当 Node C 完成一次执行，后端推送新的 Node ID 和 Edge 关系给前端，前端更新力导向图。

**3. 结果分析 (Analysis)**

- **Framing Shift 曲线：** 不依赖量化指标，而用 Semantic Distance（语义距离）。利用 Embedding 模型计算 Gen0 文本与 GenN 文本的向量距离，在时间轴下画出折线图。
- **节点显微镜：** 用户点击 UI 上的节点时，后端调取 LangGraph 存储的 State 快照，展示 input 与 output 的 diff。

### 4.2 用户点击「开始模拟」后的执行流程

**Layer 0**

- \(V_0\) = 用户上传的原始图表  
- \(V_0\) 的画像 = Source（特殊标签，代表原始发布者）

**Layer 1**

1. 从用户勾选的画像中，按转移概率表 \(P(\text{画像}|\text{Source})\) 采样 K 个。  
   例：K=3 → 采样得到 [Authority, Reframer, Adversary]  
   （只从用户勾选的画像中采样，未勾选的概率设为 0 并归一化。）

2. 每个画像-Agent 独立做一次 LLM 调用：

   - Authority 看到 \(V_0\) → resonance → forward → 产生 V1 (minor) ✓  
   - Reframer 看到 \(V_0\) → conflict → modify → 产生 V2 (significant) ✓  
   - Adversary 看到 \(V_0\) → conflict → modify → 产生 V3 (major) ✓  

   → Layer 1 共 3 个节点。

**Layer 2**

- **对 V1 (Authority)：** 按 \(P(\text{画像}|\text{Authority})\) 采样 K=3 → [Authority, Reframer, Amplifier]  
  - Authority → resonance → forward → V4 ✓  
  - Reframer → tension → modify → V5 ✓  
  - Amplifier → noise → ignore → ✗  
  → V1 有 2 个子节点。

- **对 V2 (Reframer)：** 按 \(P(\text{画像}|\text{Reframer})\) 采样 K=3 → [Adversary, Amplifier, Amplifier]  
  - Adversary → conflict → modify → V6 ✓  
  - Amplifier → resonance → forward → V7 ✓  
  - Amplifier → resonance → forward → V8 ✓  
  → V2 有 3 个子节点。

- **对 V3 (Adversary)：** 按 \(P(\text{画像}|\text{Adversary})\) 采样 K=3 → [Amplifier, Amplifier, Reframer]  
  - Amplifier → resonance → forward → V9 ✓  
  - Amplifier → noise → ignore → ✗  
  - Reframer → tension → modify → V10 ✓  
  → V3 有 2 个子节点。

→ Layer 2 共 7 个节点。

… 直到达到 `max_depth` 或全部 ignore。

### 4.3 每个 Agent 的 LLM 调用 Prompt

```text
prompt = f"""
你的画像是「{persona_label}」：{persona_description}

你的典型行为特征：
- 常用操作：{typical_operations}
- 偏移倾向：{typical_shift_range}

你现在看到了以下图表：
- 数据描述：{parent_data_description}
- 当前标题：{parent_title}
- 当前注释：{parent_annotations}
- 当前叙事：{parent_frame_narrative}

请输出 JSON：
{{
  "inner_monologue": "你看到这个图表的第一反应...",
  "action": "forward | modify | ignore",
  "gap_type": "resonance | tension | conflict | noise",
  "operations": [  // action 为 ignore 时为空
    {{"op": "select_data_range", "layer": "data", "detail": "..."}},
    ...
  ],
  "new_title": "...",
  "new_annotations": ["..."],
  "variant_narrative": "修改后的图表表达了什么叙事",
  "shift_magnitude": "none | minor | significant | major"
}}
"""
```

画像标签直接写进 Prompt——「你是 Reframer（叙事重构者）」比「你是 influencer + cause + shortform」更直观，LLM 角色扮演效果更好。

## 5. 具体 Case 演示

**场景：** 用户上传了一个关于「疫苗副作用极低」的中立图表。

**LangGraph 执行流：**

- **Step 1 (Gen 0 → 1)**  
  - Agent 1 (Role: Professional Media)：看到图表。  
  - Narrative Gap：小，认同数据的专业性。  
  - Decision：Pro→Pro 模式。  
  - Action：仅修改配色 (Visual Color)，使其更符合新闻规范。  
  - Topology：线性延伸。

- **Step 2 (Gen 1 → 2)**  
  - Agent 2 (Role: Network Influencer)：看到 Agent 1 的图。  
  - Narrative Gap：大；Agent 2 设定为「反疫苗阴谋论者」，认为「数据被操纵了」。  
  - Decision：Adverse（对抗）模式。  
  - Action：  
    1. Tool: Data_Range_Select（只截取副作用出现的那一小段数据）。  
    2. Tool: Annotation_Add（加标题：「真相被掩盖了！」）。  
  - Topology：触发分叉 (Branching)；原图可能继续被其他中立媒体引用，此处产生「突变」分支。

- **Step 3 (Gen 2 → 3)**  
  - Agent 3 (Role: Citizen Curator)：看到 Agent 2 的图。  
  - Narrative Gap：小，被 Agent 2 的情绪感染。  
  - Decision：Evaluate（评价）模式。  
  - Action：纯转发 + 情绪化评论（「太可怕了」）。  
  - Topology：线性延伸，但偏移程度 (Shift) 达到 Significant。

**说明：** UI 右下角偏移量的计算可用中间量呈现，或不显示。
