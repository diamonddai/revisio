# 编码指南 / Codebook

---

## 一、角色类型 Role (Who)

### 1. Bridger（桥接者）

**理论来源**：Frame Alignment Processes, Micromobilization, and Movement Participation

**核心功能**：连接数据与公众，建立信息传播的基础链路

**定义**：Bridger 是数据可视化传播链条中的"源头角色"，主要由政府机构、官方组织、科研机构或第三方数据平台担任。其核心任务是将原始数据以相对客观、完整的方式公开呈现给公众，建立数据与受众之间的结构性连接。

**典型特征**：
- 配色相对客观
- 数据完整
- 有数据来源
- 以信息告知为主要目的，而非说服或动员

**语料库示例**：ONS 发布死亡登记数据、NOAA 更新全球温度数据、科研机构发布疫苗相关研究数据等。

---

### 2. Extender（延伸者）

**核心功能**：将原有议题延伸至更广泛的关联领域，扩展框架的解释范围

**定义**：Extender 在保留原始数据的基础上，通过引入新变量、新维度或关联议题，将讨论从单一问题扩展到更宏观的社会、经济或政治语境中。其目的是增加议题的关联性和动员潜力，吸引原本对核心议题不敏感的受众群体。

**典型操作手法**：
- **增加变量数据系列**：在原图基础上增加对比变量（如在通胀率图上叠加医疗支出增长率）
- **修改标题扩展议题**：改变标题将"疫情死亡上升"延伸为"疫情如何影响超额死亡率"
- **增加注释扩展议题**：引入历史关键事件作为参照系（如标注经济危机、政策转折点）
- **时间线拓展**：延展数据时间范围以建立历史纵深感

**语料库示例**：从 US inflation rate 延伸到 price inflation for all items；在失业率图中增加大学毕业生失业率对比；在通胀数据中标注历史关键事件等。

---

### 3. Adverser（对抗者）

**核心功能**：构建与主流叙事相对立的解读框架，挑战既有共识

**定义**：Adverser 通过选择性呈现数据、重新框定因果关系或直接否定主流解读，构建与官方或主流媒体叙事相矛盾的替代性框架。其目的可能是政治动员、阴谋论传播，或对主流叙事的正当质疑。

**典型操作手法**：
- **截取数据范围**：选取特定时间段数据支持相反结论（如截取降温周期数据声称"全球变冷"）
- **来源删除**：移除原始数据出处，削弱可追溯性和可信度检验
- **修改配色**：将原本强烈的对比色调改为温和配色，淡化问题严重性

**语料库示例**：社交媒体截取 NOAA 数据的特定时段声称全球变冷；个人博客修改配色弱化数据对比强度。

---

### 4. Amplifier（放大者）

**核心功能**：强化既有叙事框架，提升特定议题的显著性与情感冲击力

**定义**：Amplifier 在不改变核心议题的前提下，对原始数据进行"信号增强"，使特定解读更加突出、鲜明、易于感知。其目的是让受众更强烈地认同某一框架。

**典型操作手法**：
- **修改配色**：使用高对比度、情感暗示性强的颜色方案
- **坐标轴简化**：删除冗余信息，聚焦核心数据
- **修改标题**：使用主题明确的标题（如"deaths are rising"）
- **添加注释**：添加指向性注释，引导读者解读方向
- **修改注释**：通过颜色、加粗、大写突出注释，标注关键数据点
- **纵横比调整**：通过拉伸/压缩图表比例放大变化幅度
- **坐标轴尺度调整**：通过拉伸/压缩坐标轴比例放大变化幅度
- **时间截取**：选取特定时段数据以强化趋势感知
- **增加背景**：通过增加主题对应背景引发观众情感共鸣

**语料库示例**：BBC 将面积图配色改为更醒目的方案、新闻媒体截取 2006 年后数据强调森林砍伐率上升、社交媒体用大写字母和醒目颜色标注关键数据点等。

## 二、平台 Platform (Where)

| 平台类型 | 说明 |
|---------|------|
| 第三方数据平台 | Wikipedia、YCharts 等 |
| 个人网站/博客 | 个人运营的网站、博客 |
| 科研机构 | 书籍、学术文献、选举实验室等 |
| 在线社区/UGC平台 | 各种论坛 |
| 社交媒体 | Twitter、YouTube |
| 新闻媒体 | BBC、JFP 等新闻媒体 |
| 政府/官方机构/国际组织 | 政府、官方数据发布来源、世界经济论坛 |
| 机构博客 | 企业、机构运营的博客网站 |

## 三、框架操作 Frame Operation (How)

### 数据层面 (Data)

| 操作 | 说明 |
|-----|------|
| select data variables | 筛选呈现的数据系列 |
| add data variables | 增加呈现的数据系列 |
| select time range | 选择时间范围 |
| add time range | 增加时间范围 |
| change data granularity | 修改数据呈现粒度（如日均变月均） |

### 视觉层面 (Visual)

| 操作 | 说明 |
|-----|------|
| change chart type | 改变图表类型 |
| change chart color | 改变图表颜色 |
| add background to the chart | 给图表增加背景 |
| simplify chart axis | 简化坐标轴（以突出其他信息） |
| change aspect ratio | 改变图片纵横比 |
| change axis scale | 改变坐标轴尺度（如缩小纵轴尺度以拉高） |

### 文本层面 (Text)

| 操作 | 说明 |
|-----|------|
| add title | 增加标题 |
| change title | 改变标题 |
| add annotation | 增加注释 |
| change annotation | 改变注释 |
| delete source | 删除数据来源 |
| change legend description | 改变图例描述 |

## 四、偏移程度 Shift Magnitude

| 程度 | 说明 |
|-----|------|
| none | 无变化 |
| minor | 框架基本保持，仅细节变化 |
| significant | 核心叙事发生可识别的改变 |
| major | 框架几乎完全偏离或反转原始含义 |

## 五、分叉触发 Branch Trigger

| 类型 | 理论来源 | 说明 |
|-----|---------|------|
| cross_platform | Platform Affordances (Bucher & Helmond, 2017) | 同一内容被搬运到不同平台 |
| role_divergence | Gatekeeping Theory (Shoemaker & Vos, 2009) | 不同角色对同一内容做出不同解读 |
| none | — | 线性传播 |
